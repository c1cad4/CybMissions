# CybMissions

Полезные задания, обучение и подтверждение достижений

## Статус

Архитектурный проект: реализация этого компонента ещё не создана.
Название и описание определяют направление, но не подтверждают готовую возможность.

## Место в системе

[Границы подсистем](https://github.com/c1cad4/cybOS/blob/main/docs/NEW_COMPONENTS.md)
поясняют связь с существующими модулями. Рабочая вертикаль агентов и памяти
находится в [CybCore](https://github.com/c1cad4/CybCore).

## Критерии следующей реализации

- Явный контракт входных данных, результатов и ошибок.
- Сквозной сценарий с существующим интегратором вместо отдельного несвязанного demo.
- Тесты отказов, соответствующие назначению компонента.
- Реальные измерения или отчётливо обозначенная симуляция.
